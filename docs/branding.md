# Branding visual

## Referencia

El tratamiento visual de la app sigue el estilo sobrio usado en dashboards MIDE
relacionados:

- fondo blanco;
- encabezados azul institucional;
- controles compactos;
- acciones principales en verde/teal;
- banda inferior multicolor como referencia visual secundaria.

## Reglas de uso

- Mantener el logo en encabezado, sin repetirlo en cada seccion.
- Priorizar legibilidad y operacion sobre decoracion.
- No usar imagenes UBO descargadas desde fuentes no autorizadas.
- Si se recibe un manual de marca oficial, actualizar este documento y
  `app/ui/branding.py`.
